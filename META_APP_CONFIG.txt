Adicionar no painel do Meta App em:

  Para desenvolvimento local:
    http://localhost:4100/api/integrations/connect/meta/callback

  Para produção (Railway):

=== FLUXO DO OAUTH ===
1. Usuário clica "Conectar Meta Ads" no TrackROI
2. Abre popup → /api/integrations/connect/meta?token=XXX
3. Backend redireciona para Facebook OAuth:
   https://www.facebook.com/v22.0/dialog/oauth?client_id=1033357322852273&redirect_uri=<BACKEND_ORIGIN>/api/integrations/connect/meta/callback&...
4. Facebook redireciona de volta para o callback com ?code=...&state=...
5. Backend troca code por access_token e salva a integração

O erro "domínio não incluído nos domínios do app" ocorre porque o
redirect_uri aponta para um domínio que não está autorizado no app da Meta.
